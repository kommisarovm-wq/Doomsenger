# Doomsenger

Doomsenger is a dark-themed messenger prototype. Visitors fill in a short registration form (email, phone, gender, date of birth) and land on the chat list, with an animated cat mascot in the header and live search over chats.

## Technologies

- Plain HTML, CSS, and vanilla JavaScript in a single `index.html` — no build step
- Hosted on Netlify as a static site (`netlify.toml` publishes the repo root)

## Running locally

Open `index.html` in a browser, or run `netlify dev --port 8889` to serve it locally.
